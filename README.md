# ✨ Sobre o Projeto

A **MonikaBot-MD** é uma bot WhatsApp Multi Device moderna, rápida e totalmente otimizada para entregar uma experiência completa dentro do WhatsApp.

Desenvolvida com foco em:
- desempenho
- estabilidade
- visual moderno
- comandos organizados
- integração com IA
- automações avançadas
